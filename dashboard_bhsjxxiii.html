    Assistente de Dados
    Pergunte sobre especialidades, exames, categorias ou municípios — cálculo instantâneo, sem depender de internet.
    Nota de qualidade de dados — Todos os valores deste painel foram extraídos linha por linha, coluna por coluna, diretamente da planilha oficial, com leitura programática — sem digitação manual.
    Como atualizar após cada expedição — Rode "gerar_dashboard.py" apontando para a planilha .ods atualizada. O script detecta automaticamente todas as abas de ano (2025, 2026, 2027...), recalcula tudo e gera um novo dashboard.html pronto para publicar. Nenhuma edição de código é necessária.
